# 璇兒字音字形比賽練習

以基隆市國小字音字形比賽為主要練習目標，建立可持續擴充、可追溯來源的線上題庫與練習網站。

## 目標與比賽規格
- 對象：國小學生組；練習難度以正式縣市級競賽為準，不限於單一年級課本。
- 基隆市 115 年競賽規格：字音 100 題、字形 100 題，作答時間 10 分鐘，每題 0.5 分。
- 字音依教育部《國語一字多音審訂表》；字形依教育部常用字標準字體。
- 歷屆全國賽、基隆市正式賽、其他縣市賽及校內練習題必須分開標示，不可混稱。

## 專案原則
1. 每題保留來源網址、年度、組別與頁碼等可追溯資訊。
2. 未核對答案的題目標示為待覆核，不直接當成正式答案。
3. 不把搜尋摘要或 OCR 文字直接當作已驗證題目。
4. 線上練習作為輔助；正式模擬仍應搭配紙筆書寫。

## 專案結構
- `index.html`：網站入口與目前的前端骨架。
- `data/sources.json`：題庫來源登錄表。
- `data/questions/`：依年度與競賽類型整理的題目資料。
- `data/schema/question.schema.json`：題目資料格式。\n- `scripts/extract_pdf_pages.py`：歷屆 PDF 逐頁文字抽取工具（只產生待校對稿）。\n- `docs/PDF-IMPORT.md`：PDF 取得、抽取、校對與正式入庫流程。
- `docs/ROADMAP.md`：建置順序與驗收標準。

## 目前資料狀態
目前已建立可操作的 MVP：字音/字形示範練習、答案判斷、錯題本、作答統計與瀏覽器本機保存。示範題僅用於測試功能，不代表正式歷屆題目。歷屆題庫仍在蒐集與驗證中，未核對題目不會混入正式題庫。

## 本機預覽
此版本為純靜態網站，可直接以瀏覽器開啟 `index.html`；部署至 Vercel 時可使用專案根目錄作為靜態輸出。
